# 景氣循環六階段：監測指標研究

> 本文件依據元大投顧「景氣循環圖」（六階段模型）建立一套**可量化、可自動化更新**的指標體系。
> 目的不是預測，而是**定位**：回答「我們現在大概在哪一段？」以及「下一段的轉折訊號長什麼樣？」

---

## 0. 摘要：一句話結論

原圖的六個階段，本質上是由**兩個軸**旋轉出來的：

| 軸 | 內容 | 決定了什麼 |
|---|---|---|
| **成長軸 (G)** | 實體經濟動能的**水準**與**方向** | 股票（盈餘） |
| **通膨軸 (I)** | 物價／原物料的**水準**與**方向** | 債券（折現率）、原物料 |

- **債券價格**箭頭（階段1-3↑、4-6↓）＝ 利率循環，落後於通膨軸約 2–4 季
- **股票價格**箭頭（階段2-5↑、6及1↓）＝ 盈餘預期循環，**領先**實體經濟約 6–9 個月
- **原物料價格**箭頭（階段3-5↑、6及1-2↓）＝ 同時／略落後於實體需求

因此監測系統的核心 = **用領先指標定位 G 與 I 的「方向」（一階）與「加速度」（二階）**，
再用同時指標確認、用落後指標驗屍。這與 Merrill Lynch Investment Clock 的邏輯一致，
但本圖把「復甦」與「擴張」、「高峰」與「趨緩」拆得更細，所以**二階微分（動能是否鈍化）非常關鍵**
——階段4與階段5的差別，不在於經濟好不好，而在於**成長率還在不在加速**。

---

## 1. 指標分層架構

監測系統必須分四層，混用會導致誤判（最常見的錯誤是拿失業率當轉折訊號，那是落後指標）。

### L1 領先層（提前 3–12 個月）— 負責「換檔」
利率敏感部門、訂單、信心、金融條件。**權重最高，但雜訊最大。**

### L2 同時層（0–1 個月）— 負責「確認」
生產、就業、銷售、所得。用來確認 L1 的訊號不是假的。

### L3 落後層（落後 3–12 個月）— 負責「驗證與防止過早轉向」
失業率、單位勞動成本、存貨率、企業放款、服務類通膨。
**唯一用途：確認前一階段已結束**，絕不可用來預測。

### L4 市場內生層（即時）— 負責「早期預警」
殖利率曲線、信用利差、產業輪動比值、原物料比價。
市場本身就是領先指標的加總，**更新頻率最高（日頻）**，適合做為 L1 的即時代理變數。

## 3. 六階段對照表（監測 Signature）

下表是本研究的核心產出：每一階段應該看到什麼組合。

### 階段 1：景氣衰退（債↑ 股↓ 原物料↓）
- **G**：水準 < 0 且**仍在下滑**（二階為負）
- **I**：由高檔快速滑落
- **必要條件**：ISM < 48 且續降、初領失業金 4 週均突破前一年高點、LEI 6M 年化 < −3.5%、HY OAS 快速走闊
- **確認訊號**：Sahm Rule 觸發（0.50）、非農轉負、CFNAI-MA3 < −0.7
- **曲線型態**：倒掛結束、**牛市陡峭化**（短率跌得比長率快）＝央行開始降息 → 債券價格上漲
- **市場**：防禦股相對強勢、VIX 逆價差、EPS 下修廣度極端
- **常見誤判**：此時失業率剛開始上升，很多人誤以為「才剛要壞」，但股票其實已跌了 6–9 個月

### 階段 2：景氣谷底（債↑ 股↑ 原物料↓）
- **G**：水準仍在低檔，但**二階轉正**（下滑速度減緩）← **這是最關鍵的判斷**
- **I**：仍在下滑（通膨落後於成長）
- **轉入訊號**：初領失業金**見頂回落**、ISM 新訂單率先回升至 50 上方（但總指數仍 < 50）、建照核發止跌、存貨／銷售比見頂
- **金融面**：降息循環進行中、HY OAS 見頂回落、小型股與高 Beta 股領先反彈
- **台灣**：M1B 年增率回升並向上穿越 M2（黃金交叉）、景氣燈號藍燈但分數止跌
- **圖中矛盾點解讀**：原物料仍跌、股票卻漲 → 典型的「**流動性行情／本益比擴張**」，盈餘尚未回升，靠折現率下降推動

### 階段 3：景氣復甦（債↑ 股↑ 原物料↑）
- **G**：水準轉正、二階為正（加速）
- **I**：**由負轉正但仍低**（通膨落底回升，尚未構成升息壓力）
- **轉入訊號**：ISM 站上 50、IP 年增轉正、EPS 修正廣度由負轉正、銅價與 BDI 同步走升、PPI 年增觸底
- **債券仍漲的原因**：央行尚未轉鷹、實質利率仍下行；此階段**股債商品齊漲**，是資產配置最甜蜜的一段
- **台灣**：外銷訂單年增轉正、出口連續 2–3 個月年增正成長、燈號由藍轉黃藍

### 階段 4：景氣擴張（債↓ 股↑ 原物料↑）
- **G**：水準高、二階仍為正
- **I**：明確上行，核心通膨升破目標
- **轉入訊號**：**債券箭頭翻向** ← 這是階段3→4的分界。10Y 殖利率上行、Fed 由降轉升或暗示縮減寬鬆、5y5y 通膨預期走升
- **同步**：就業市場緊俏（職缺率高、離職率高 `JTSQUR`）、薪資成長加速、產能利用率上升
- **台灣**：燈號綠燈、景氣對策信號分數穩定在 23–31

### 階段 5：景氣高峰（債↓ 股↓ 原物料↑）
- **G**：水準仍高，但**二階轉負 —— 動能鈍化**（成長率的高點已過）
- **I**：續揚，甚至加速（通膨落後於成長，所以在成長見頂後才衝頂）
- **轉入訊號（最重要的一組）**：
  - ISM 由高檔（>57）連續 2–3 個月回落
  - 殖利率曲線開始**平坦化(bear flattening)**，2Y 上行快於 10Y ← 緊縮過頭的前兆
  - 實質利率轉正並持續上升
  - 循環股／防禦股比值**見頂**
  - EPS 上修廣度見頂、股價漲勢由指數集中於少數權值股（breadth 惡化）
- **為何股票在此下跌**：估值受升息壓縮 + 市場開始定價明年的盈餘下滑
- **台灣**：燈號紅燈／黃紅燈、出口年增率高基期、記憶體價格見頂

### 階段 6：景氣趨緩（債↓ 股↓ 原物料↓）
- **G**：轉負、二階為負
- **I**：**見頂回落**（原物料箭頭翻向 ← 階段5→6 的分界）
- **轉入訊號**：ISM 跌破 50、新訂單 − 存貨轉為負值、建照核發連 3 個月下滑、SLOOS 放款標準大幅收緊、HY OAS 開始擴大
- **債券仍跌的原因**：央行為壓通膨而維持高利率（policy lag），**這是最痛苦的一段：股債商品齊跌**
- **離開訊號（→階段1）**：央行政策轉向、曲線由倒掛轉陡、初領失業金明顯上升

## 4. 量化評分與狀態機

### 4.1 兩個合成分數

對每個指標 $x$ 計算 z-score（建議用 10 年滾動窗，或對趨勢類指標用 6 個月年化變動率）：

```
G_t = Σ w_i · z(growth_i, t)      # 成長分數
I_t = Σ v_j · z(inflation_j, t)   # 通膨／原物料分數
```

再取**動能（二階）**：

```
dG = G_t − G_{t−3}   （3個月變化，抑制單月雜訊）
dI = I_t − I_{t−3}
```

### 4.2 階段判定規則

| 階段 | G 水準 | dG | I 水準 | dI |
|---|---|---|---|---|
| 1 衰退 | < 0 | < 0 | 下滑中 | < 0 |
| 2 谷底 | < 0（低檔） | **≥ 0** | 仍低 | < 0 |
| 3 復甦 | 由負轉正 | > 0 | 低檔回升 | **≥ 0** |
| 4 擴張 | > 0 | > 0 | > 0 | > 0 |
| 5 高峰 | > 0（高檔） | **< 0** | > 0 | > 0 |
| 6 趨緩 | 由正轉負 | < 0 | 高檔 | **< 0** |

**防抖規則（必要）**：
1. 需**連續 2 個月**滿足新階段條件才換檔，避免 whipsaw
2. 階段只能**依序推進或停留**，不可跳階（1→3 視為資料異常，需人工檢視）
3. 例外：外生衝擊（疫情、戰爭）可容許快速跳階，需以 HY OAS 單月跳升 > 150bp 作為「衝擊模式」旗標

## 5. 常見假訊號與防呆

| 陷阱 | 說明 | 防呆做法 |
|---|---|---|
| **製造業 PMI 假衰退** | 2012、2015-16、2019、2022-23 均曾 ISM < 50 卻無衰退 | 必須同時看服務業 PMI 與就業；單一模組不可決策 |
| **殖利率曲線倒掛即賣出** | 倒掛到衰退平均 12–18 個月，期間股市常大漲 | 用「倒掛**解除**且降息啟動」作為階段1訊號，而非倒掛本身 |
| **LEI 連續下跌** | 2022–2023 LEI 連跌 20 個月卻未衰退（金融類權重失真） | 看**擴散指數**而非只看總值；LEI 僅佔 G 分數一部分 |
| **失業率當轉折點** | 純落後指標 | 只用於事後確認 |
| **基期效應** | YoY 在極端年份後會嚴重失真（如 2021 vs 2020） | 並列 YoY 與 3M/6M 年化環比 |
| **資料修正** | 非農、LEI、OECD CLI 均大幅回溯修正 | 保存 **vintage（即時當下版本）** 資料，回測必須用 real-time data，否則會嚴重高估模型能力 |
| **台美循環不同步** | 台灣是出口／半導體循環，與美國內需循環可脫鉤 | 台灣模型應以「全球貿易＋半導體」為主軸，不可直接套用美國模板 |

## 6. 建議的最小可行監測儀表板

**更新排程**
| 頻率 | 抓取內容 |
|---|---|
| 日 | 殖利率曲線、HY/IG OAS、銅金比、油價、商品指數、產業輪動比值、美元 |
| 週 | 初領失業金、NFCI、SCFI |
| 月 | ISM/PMI、建照、IP、非農、CPI/PPI、LEI、OECD CLI、台灣燈號／外銷訂單／台積電營收 |
| 季 | SLOOS、GDP、企業獲利 |

**輸出**
1. 當前階段 + 信心度（滿足條件的指標佔比）
2. G/I 散布圖（時鐘圖），標出過去 24 個月軌跡
3. 各指標紅綠燈表（含 z-score 與 3 個月變化）
4. 「距離換檔還差什麼」清單：列出尚未滿足的下一階段條件

**資料來源優先序**
1. FRED API（免費、穩定、有 vintage/ALFRED）
2. 國發會景氣指標查詢系統（台灣官方）
3. yfinance／期貨（日頻市場資料）
4. 財經 M 平方、TradingEconomics（作為交叉核對，注意授權）
